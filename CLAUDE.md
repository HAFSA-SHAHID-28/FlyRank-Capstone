# Project Instructions

## Project

This repository contains Hafsa Shahid's FlyRank Front-End AI Engineering capstone project.

## Purpose

The project should demonstrate thoughtful frontend development, user-centered thinking, clean UI implementation, and practical use of AI-assisted development.

## Planned Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- Git
- GitHub

## Design Principles

- Clean
- Minimal
- Modern
- Responsive
- Accessible
- User-centered
- Consistent visual system

## Code Conventions

- Use functional React components.
- Prefer reusable components.
- Use semantic HTML where appropriate.
- Keep components focused and maintainable.
- Avoid unnecessary dependencies.
- Keep styling consistent with the project's design system.
- Use clear and descriptive naming.
- Do not modify unrelated files.

## AI Development Guidelines

- Understand the existing code before making changes.
- Explain important changes when requested.
- Prefer simple solutions over unnecessary complexity.
- Do not introduce major dependencies without a clear reason.
- Preserve existing functionality when modifying code.
- Do not overwrite working code without understanding its purpose.
- Keep accessibility and responsiveness in mind.
- Verify changes after implementation.
