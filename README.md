# FlyRank Capstone

Personal capstone project developed as part of the FlyRank Front-End AI Engineering Internship.

## Overview

This repository contains the development work for my FlyRank capstone project.

The project focuses on building a thoughtful, user-centered frontend experience while applying modern frontend development practices and AI-assisted development workflows.

## Capstone Objectives

This capstone will demonstrate the ability to translate a user need into a polished frontend product. The completed project will prioritize:

- A clear, task-focused user experience informed by user-centered design
- A responsive, accessible interface built with semantic HTML and reusable React components
- A clean, consistent visual system implemented with Tailwind CSS
- Thoughtful use of AI-assisted development for ideation, implementation, iteration, and refinement
- Maintainable, well-organized code supported by Git and GitHub workflows

## Tech Stack

- Vite
- Git & GitHub
